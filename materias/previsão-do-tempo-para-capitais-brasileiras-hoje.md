A previsão do tempo para as capitais brasileiras hoje é a seguinte:

São Paulo está previsto para ter uma temperatura de 20 graus Celsius com chuvas isoladas. Já o Rio de Janeiro terá uma temperatura de 28 graus Celsius com pancadas de chuva à tarde.

Em Brasília, a temperatura está prevista para ser de 19 graus Celsius com céu aberto. Salvador, por sua vez, terá uma temperatura de 27 graus Celsius com ensolarado.

Porto Alegre está previsto para ter uma temperatura de 16 graus Celsius com frio e névoa úmida. Já Manaus terá uma temperatura de 33 graus Celsius com abafado e pancadas de chuva.

Essas são as condições climáticas previstas para as capitais brasileiras hoje.
